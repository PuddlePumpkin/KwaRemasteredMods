# Kwa Remastered Mods ✨
Repository for my UE4SS Oblivion Remastered Mods

⚠️ **Note:** *No original game assets (textures, meshes, or code) are included in this repository.*
This project is **NOT** associated with Bethesda, Zenimax, Virtuos or any of their subsidiaries!

### Mods: 

*   **[Kwa Configs](docs/ConfigReadme)**: A framework mod that allows other mods to register and add simple UI elements for configuration. Parameters are automatically saved when set.

*   **[Kwa Notifications](docs/NotifsReadme)**: A replacement for the base notification system. Featuring stacking notifications, debug printing, and integrated with Kwa Configs to add options for appearance.
